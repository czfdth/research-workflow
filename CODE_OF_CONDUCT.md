# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be direct about the work and decent to the people doing it. Critique
claims, evidence and code; do not attack contributors. Harassment, discriminatory
language and personal attacks are not welcome in issues, pull requests or any
other project space.

Reports go to the maintainer via the contact in [SECURITY.md](SECURITY.md).
Reports are handled privately, and the maintainer may remove comments, close
threads or block accounts when the standard is not met.
